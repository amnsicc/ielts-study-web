## D2b-R1体验调整

- 每个母词及拓展有“编辑次数”窗口，预填已保存总次数，可直接输入非负安全整数（包括0）。未改值、取消、Escape不写记录；保存失败保留输入，可重试原操作。保存中暂不取消；失败时“关闭窗口”只关窗口，未完成操作仍可在记录状态行重试。
- 次数筛选阈值默认0，比较仍“不限次数”。新页面/刷新/重开、换新篇、模块重置、清词表筛选均恢复0；只清关键词和页内返回保留本次阈值。

- 两窗口编辑同一个对象时，旧编辑会被拒绝覆盖；点击“刷新当前次数”看到最新值，再决定保存。其他对象或材料历史变化不会让当前编辑无故冲突。

## D2b新增操作

- 每个母词及拓展行有“没记住+1”和“撤销”。次数显示在原编号下，0不显示；母词多个释义共用本体次数。阅读内跨材料共用，四用途存储隔离；其他模块页面仍未开放。

### 数据位置与升级

默认保存于当前程序目录的.local-data/study-events.jsonl；不进Git/ZIP。为固定跨版本位置，可显式指定一个绝对目录，例如：

```powershell
node scripts/serve.mjs --host 127.0.0.1 --port 4187 --data-dir 'D:\IELTS-user-records'
```

升级程序时沿用同一个数据目录；不要用交付副本覆盖它。独立验收和开发自测使用各自新目录，绝不使用上述个人目录或旧Readest双库。次数/历史由本机Node服务写入，关闭标签页不会关服务；再次打开可读回。只有界面显隐、搜索等每次打开回默认。

一个记录目录只允许一个服务。若提示被占用，先核对现有服务，正常输入stop结束；异常退出的writer.lock保留，不会自动删除。确认原进程已退出后，先复制整个记录目录留证，再单独处理锁；禁止为启动而直接删事件文件。坏JSON、未知版本、尾行不完整会拒绝加载并保全文件，不清零。写入中途失败停止继续追加，需要保全诊断；普通写入前失败可重试。此方案不承诺断电或硬盘损坏零丢失。

没有旧Readest数据迁移、跨端同步/合并、记录导入/恢复，也没有录音或写作练习；听力仅实现下述L1。

仅验证电脑Chrome；560px宽截图为缩窗检查，不代表安卓或手机适配。界面最小高度520px；更矮窗口可滚动整页。

### 草稿保存与冲突

草稿自动保存到指定数据目录的listening-drafts.jsonl，记录目录身份文件data-store-id区分不同数据目录。study-events.jsonl原v1/v2次数格式不改。升级沿用同一目录，不覆盖原文件；不要把旧R200当能保存听力草稿的回退程序。服务仍用writer.lock保护单写者；坏草稿/未知版本/不完整尾行不清零，启动失败释放本次取得的锁。正常stop会等待写入结束。

输入约350ms自动提交，保存中继续输入保留最新文字；只有服务器确认才显示已保存。失败保留输入和原操作，重试不会重复追加；写中失败会停止后续追加，须保全目录后诊断。并发同篇冲突会同时保留本地稿和远端稿，先查看远端并保留需要的本地内容，再明确采用远端；采用远端有确认，不能静默覆盖。其他篇修订独立。

每个标签有本地待办保全。刷新原标签可恢复未确认输入；正常关闭原标签后重新打开，服务器已保存部分自动恢复，尚未确认部分通过“恢复待办备份”明确恢复。备份可能属于其他仍在使用的窗口，勿盲目恢复；重复已确认操作会幂等确认，远端随后有更新时需冲突处理。不同数据目录身份禁止跨目录重放。浏览器清理站点数据/隐身配置会移除本地保全；浏览器存储不可用会提示，不承诺强杀、断电时最后瞬间输入零丢失。不要在有未确认输入时清站点数据。

听力页不再提供“刷新记录/导出记录/刷新草稿/导出本地稿/导出已存草稿”，也不将它们搬入菜单。自动保存和已有记录继续保留；保存中/已保存在标题旁轻量显示，失败、冲突及发现本地待办时才出现必要的处理入口。底层保全接口仍保留用于公开HTTP检查，不代表页面导出或导入恢复功能。阅读页面默认保持原状。练习核对、首次结果冻结、订正历史尚未开放；这里的草稿不是评分结果。
