# 雅思学习区：D2b

本地浏览器demo。D1a/D1b/D2a已独立通过；本次D2b增加次数、保存、历史和导出，待本段独立验收及用户体验确认。

## 打开

本机已有Node 24。双击本目录start.cmd，保持启动窗口打开，再在浏览器访问：

http://127.0.0.1:4178/

也可在本目录执行：

```powershell
node scripts/serve.mjs --host 127.0.0.1 --port 4178
```

停止：在启动窗口输入stop后回车，等待“记录服务已正常关闭”；也支持交互终端Ctrl+C。不要强制杀进程，否则可能留下用于保护记录的占用锁。若端口已占用，先确认是否已有本demo；不要随意结束其他进程。可改用`--port 4179`并打开对应地址。不要双击index.html直接使用file://，页面需要本机服务读取资料。

## D1b新增操作

- 默认仅英文。上方“整体显示”可切仅英文、仅中文、中英都显示、全部遮挡；每个母词或拓展行右侧可分别选模式。整体切换会统一全部词条，之后可再逐条改；有不同设置时整体选择显示“逐词设置”。
- 遮挡保留行高与原编号，文字也从无障碍呈现中隐藏。全部遮挡后仍可用行右侧控制揭示，不需要靠已隐藏单词找入口。
- 有拓展的母词旁有箭头，点开在下面显示本用途的派生、特殊形式和词块。原编号不变，母词其他阅读释义仍在主行；抽屉内关联内容不代表它已在当前文章出现。
- 文章中浅绿目标可点击查看本篇用义。可用键盘聚焦后Enter打开，关闭或Escape回到原目标；背景点击也可关闭。“目标高亮”只控制颜色，关闭后仍能点已登记目标。
- 仅文章原来以反引号明确登记的40处出现可查本篇义，其他同拼写不自动装配；不是任意文章通用自动查义或词典。
- “重置阅读界面”恢复第一篇、默认46%分区、两区篇首、仅英文、拓展收起、高亮开启，并关闭弹层。仅影响本模块界面，不清D2b新增的次数和材料历史。
- 同次打开中回首页再进，保留文章、位置、逐词显隐和抽屉等状态；刷新或关页重开恢复默认。

## D2a新增操作

- 词表范围默认“当前文章”；选择“全部阅读词（001—040）”可跨两篇找词，不改变下方正文。此处全部仅指当前40组样本。
- P档可选全部/P0/P1/P2。母词或拓展任一阅读义项命中即保留完整组，仍显示各自档位。搜索与P档按母词组取交集，允许组内不同对象分别满足条件。
- 词表搜索：英文不分大小写按词条/词块开头匹配，中文释义包含匹配；完整原编号或子编号检索，例如001或1、13-D。不做语义搜索。
- 搜索结果用编号“定位”按钮，不额外揭示被遮文字。点击拓展结果会展开并定位到具体行，给约1秒提示再淡去；不改显隐或正文位置。结果可收起/重新显示；清除按钮或删空关键词保留最后定位位置，P档不清除。
- 零命中显示空态；“清除词表筛选”清关键词和P档，保留范围。切换文章恢复当前文章范围/全部P档/空词表搜索，并双区回篇首，逐条显隐不丢失。
- 文章搜索查两篇材料的标题、正文、实际目标编号/英文及本篇中文用义；不把备查义或未入篇拓展当成本文用义。输入只显示结果，点击跨篇结果才换篇并同步词表；同篇结果保留词表过滤和位置。
- 文章结果有标题与片段。标题定位标题，正文匹配定位对应段落，目标编号/中文用义定位已登记目标，可继续Enter查义。正文段落定位不是任意词的精确选区工具。
- 阅读重置同时清除两处搜索、范围和P档；页内返回保留本次状态，刷新/关闭重开默认。输入控件不因结果更新被替换。

## D2b新增操作

- 每个母词及拓展行有“没记住+1”和“撤销”。次数显示在原编号下，0不显示；母词多个释义共用本体次数。阅读内跨材料共用，四用途存储隔离；其他模块页面仍未开放。
- 撤销该对象最近尚未撤销的一次增加，已撤销事件不能再扣。保存中和失败时禁止继续点新次数，成功回执后更新数字；失败在词表顶部记录状态行提供原操作重试，不会重复增加。
- 次数条件支持>、≥、=、≤、<及非负整数阈值，与范围/P档/关键词按母词组取交集，各条件可由组内不同对象命中。0可参与筛选。选篇和界面重置清条件，但保留已保存次数。
- 文章下方显示主动打开次数和最近时间。首页主动进阅读、下拉换篇、跨篇搜索选择计一次；刷新/重置/浏览器历史导航/同篇定位不增加。读取时尚无历史会如实提示。
- 词表滚动区顶部有记录状态、重试、刷新记录和导出。两个标签共享一个服务，回到窗口或主动刷新记录后更新；不提供实时协同。JSON导出包含版本、事件、次数和历史，不含正式教材内容，不代表导入/恢复已实现。

### 数据位置与升级

默认保存于当前程序目录的.local-data/study-events.jsonl；不进Git/ZIP。为固定跨版本位置，可显式指定一个绝对目录，例如：

```powershell
node scripts/serve.mjs --host 127.0.0.1 --port 4187 --data-dir 'D:\IELTS-user-records'
```

升级程序时沿用同一个数据目录；不要用交付副本覆盖它。独立验收和开发自测使用各自新目录，绝不使用上述个人目录或旧Readest双库。次数/历史由本机Node服务写入，关闭标签页不会关服务；再次打开可读回。只有界面显隐、搜索等每次打开回默认。

一个记录目录只允许一个服务。若提示被占用，先核对现有服务，正常输入stop结束；异常退出的writer.lock保留，不会自动删除。确认原进程已退出后，先复制整个记录目录留证，再单独处理锁；禁止为启动而直接删事件文件。坏JSON、未知版本、尾行不完整会拒绝加载并保全文件，不清零。写入中途失败停止继续追加，需要保全诊断；普通写入前失败可重试。此方案不承诺断电或硬盘损坏零丢失。

没有旧记录迁移、跨端同步/冲突合并、记录导入/恢复，也没有录音、听力或写作练习功能。

仅验证电脑Chrome；560px宽截图为缩窗检查，不代表安卓或手机适配。界面最小高度520px；更矮窗口可滚动整页。

## 资料与隔离

教材只读取本项目data/；个人记录仅写指定新目录，不访问旧Readest程序或学习双库，不向原材料写入。无需网络、npm依赖、安装程序或账户。可在开发者工具网络页确认所有资源来自127.0.0.1。

catalog为001—040的阅读选义，包含40组、25条阅读拓展；materials为两篇固定原文，40处目标位置绑定已有本篇选义。source-manifest.json记录八份直接来源与SHA-256。本次未引入原Readest源码、依赖、商标资产或程序壳。

scripts/prepare-sample.py只供开发追溯，依赖原工作区来源路径和Python；正常运行、复制本项目和验收页面均不需要Python或旧工作区。源码和data一起复制到其他目录仍可用Node启动。

## 复跑

在本项目根执行：

```powershell
node --test
```

真实浏览器验证需要本机已安装agent-browser原生CLI和Chrome，服务先启动；输出目录必须尚不存在：

```powershell
node scripts/verify-browser.mjs --output 'D:\IELTS-D1b-evidence-new'
node scripts/verify-search-browser.mjs --output 'D:\IELTS-D2a-search-evidence-new'
```

该脚本用独立浏览器会话，完成后只关闭自己的会话，不接管个人标签页。默认CLI与Chrome路径对应本机；其他机器可分别通过进程环境变量AGENT_BROWSER_EXE和CHROME_PATH指定现有可执行文件。输出逐条CLI命令、退出码、快照、截图和result.json；失败同样保留。`--url`可指定本机另一个端口。

第一个脚本回归D1a/D1b；第二个验证D2a，二者输出目录和会话各自独立。均可用--url指定独立本机端口。来源复核可执行python scripts/check-sources.py，仅在原资料路径存在的机器上使用，不运行教材发布器。

开发自测不等于独立验收通过。本增量交验后停止，等用户转达结论，不自动进入下一模块。


D2b完整记录浏览器验证（自动建立独立数据目录、临时本机服务，并正常关闭；不使用个人记录）：

```powershell
node scripts/verify-records-browser.mjs --output 'D:\IELTS-D2b-records-evidence-new'
```

该脚本主流程使用已安装agent-browser/Chrome，下载验证因本机agent-browser下载取消问题使用现有Playwright，不安装依赖。现有路径为旧工程apps/readest-app/node_modules/playwright；其他机器可通过PLAYWRIGHT_PATH指定已有包。只有开发验证需要它，正常使用网页不需要旧工程。脚本隔离注入写入前失败、回执丢失和延迟读取，检查重试、两标签、真正进程重开以及真实下载解析。故障控制只存在于scripts/records-test-server.mjs，不存在于产品HTTP API。

公开接口、存储格式及边界详见docs/records.md。记录类Node测试会保留系统临时目录中的数据用于复核，不接触用户目录；CLI停止测试使用4198端口，若被占用会失败，不结束其他服务。
