# D1a 界面设计与自查

用途：电脑上直接阅读、对照词表；参照用户上下分区手绘，不沿用Readest应用壳。

- 颜色：底色#F4F6F8，内容#FFFFFF，正文#192C36，次字#536771，强调#176C63，分界#D8E1E5。主要释义红字沿用资料信息，以#AD342C呈现。
- 字体：中文使用Microsoft YaHei UI/系统无衬线；英文词条和文章使用Georgia/系统衬线。正文20px，行高1.85，约75字符行宽；控件14px。
- 首页四个等权入口，2×2排列；不增加仪表盘或学习进度。
- 阅读顶栏固定返回入口；上方词表、下方文章各自滚动，中间可拖动和键盘调整。内容左对齐，原编号单列，英文和各中文用义对齐；释义随内容自然增高。

```text
首页                  阅读
阅读      听力        返回首页  / 阅读          001—040
写作      口语        单词       本篇001—020
                      编号 | 英文 | 本用途各释义与档位
                      ────── 可拖动分隔 ──────
                      文章     [选择文章]
                      标题、真实目标编号、原文
```

实施前自查：采用轻边界与留白服务词表对齐，取消装饰性统计、渐变和无意义编号。首页四格仅对应用户明确的四模块；分隔条是本次主要操作特征。保留普通控件及可见焦点，界面不展示内部数据库或技术名词。

D1a历史范围：当时未实现显隐、抽屉、查义弹层、高亮开关。本文的两篇阅读材料只含母词目标，材料头如实注明未额外选入拓展项；D1b增加可查看的关联拓展，不改材料的实际覆盖范围。

## D1b实施前设计与自查

继续D1a已获认可的六色体系、字体与上下布局，不增侧栏或书库壳。上方工具条放整体显隐和重置；每行用小下拉选择单条模式，编号旁的箭头只展开拓展项。遮挡保留原格尺寸与控制，中文/英文文本不在无障碍名称中泄露。正文目标用低饱和浅绿强调，关闭高亮仍可点击/键盘查本篇义。

本篇义用紧凑原生对话框显示词、词性、当前义及来源上下文提示，关闭/Escape后返回原目标。词表变化只更新词表，不重绘文章，避免扰动阅读位置；小窗口工具条自然换行。

自查取舍：删除“未实现”的旧假控件思路，只加入本段真实动作；不重新设计首页，不引入装饰动效。重置回第一篇、46%分区、仅英文、拓展收起、高亮开启；不增加任何个人记录写入。

## D2a实施前设计与自查

保留底色#F4F6F8、纸面#FFFFFF、正文#192C36、次字#536771、强调#176C63、边界#D8E1E5；沿用中文系统无衬线和英文Georgia。阅读与词表仍是主体，搜索只是窄工具行，不增加侧栏、仪表盘或弹窗。

```text
单词  [整体显示] [重置]
[当前文章/全部001—040] [全部P档] [搜词____] [清除]
搜索结果：原编号按钮（按需展开）
编号 | 英文 | 阅读释义 | 单条显示    ← 独立滚动
──────── 可调分隔 ────────
文章 [高亮] [选择文章]
[搜索文章____] [清除] → 标题与命中片段结果（按需展开）
标题、目标编号、正文                  ← 独立滚动
```

全部左对齐，工具行自然换行且结果列表限高可滚动；关闭结果后保留定位。搜索结果只呈现编号/定位按钮，避免绕过词表遮挡揭示答案；文章结果呈现原文片段和本篇用义。短暂定位底色约1秒淡去，减少动态偏好时取消渐变仍给出短暂静态提示。空态明确提供清除条件。

自查：保持现有双区，不把新控件都挤进已有顶栏；将结果收纳为可关闭的搜索面板，给正文留下实际可阅读面积。输入节点不随结果重绘，避免中文输入法丢焦点。仅重绘词表时不动正文。每次仅实现已获确认的D2a动作，无计数假按钮。
