# D1a 界面设计与自查

用途：电脑上直接阅读、对照词表；参照用户上下分区手绘，不沿用Readest应用壳。

- 颜色：底色#F4F6F8，内容#FFFFFF，正文#192C36，次字#536771，强调#176C63，分界#D8E1E5。主要释义红字沿用资料信息，以#AD342C呈现。
- 字体：中文使用Microsoft YaHei UI/系统无衬线；英文词条和文章使用Georgia/系统衬线。正文20px，行高1.85，约75字符行宽；控件14px。
- 首页四个等权入口，2×2排列；不增加仪表盘或学习进度。
- 阅读顶栏固定返回入口；上方词表、下方文章各自滚动，中间可拖动和键盘调整。内容左对齐，原编号单列，英文和各中文用义对齐；释义随内容自然增高。

```text
首页                  阅读
阅读      听力        返回首页  / 阅读          001—040
写作      口语        单词       本篇001—020
                      编号 | 英文 | 本用途各释义与档位
                      ────── 可拖动分隔 ──────
                      文章     [选择文章]
                      标题、真实目标编号、原文
```

实施前自查：采用轻边界与留白服务词表对齐，取消装饰性统计、渐变和无意义编号。首页四格仅对应用户明确的四模块；分隔条是本次主要操作特征。保留普通控件及可见焦点，界面不展示内部数据库或技术名词。

本增量：显隐、抽屉、查义弹层、高亮开关尚未实现，不设置假按钮。本文的两篇阅读材料只含母词目标，材料头如实注明未额外选入拓展项。
